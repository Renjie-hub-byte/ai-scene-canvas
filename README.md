# AI 场景串联画布（scene-flow）

把「高管 × 通用办公」的 21 个 AI 落地场景，串成**一天**的画布：谁在什么时候做什么、人和 AI 如何接力、每条连线传递什么产物。

## 这张画布怎么读

- **四条泳道**：老板（白底）/ 老板的 AI（蓝底）/ 员工（白底）/ 员工的 AI（蓝底）。白 = 人在判断和拍板，蓝 = AI 在整理和执行。
- **主链按一天排布**：早间双方 AI 各出简报 → 老板拍板 + 一句话派单 → 员工 AI 调部门知识库备料 → 员工确认 → AI 备料拉会、材料包分发各方 AI → 各方 AI 会前预备 → 15 分钟短会 → 纪要闭环 → 傍晚回报 + 审核 → 晚间统一整理收口。
- **每条连线都是一件真实流转的产物**：信息流（蓝）/ 任务流（青）/ 决策流（橙）/ 资产流（紫）。
- **点开任意节点 / 卡片**：看这一环的对话细节（AI 和人怎么交互）+ 它在产物链里的上下游。
- **▶ 播放这一天**：按顺序自动走一遍主链。
- **随时事件带**：审批、报销、差旅、咨询等不占时段、事件触发的场景。
- **周期事件带**：周报（每周）、创新提报（每月）、绩效（每季）等低频场景。
- **重复动作 → 沉淀 → 复用**：独立闭环模块，集团 skill 库是底座，沉淀与取用在其上方滚动循环。
- **落地标注**：✅ 企微原生能跑 / 🔧 需系统打通 / ⚙️ 需定制。

## 改内容 = 改剧本，不改代码

仓库采用「剧本 / 渲染 / 构建」三件套分离：

```
剧本.json        ← 全部内容：节点、对话、连线、事件带、周期带、池
画布模板.html     ← 通用渲染引擎（布局、连线、抽屉、播放）
build_canvas.py  ← 构建：注入剧本 + 自动校验
```

改完 `剧本.json` 后重建：

```bash
python3 build_canvas.py
```

构建时自动校验：21 个场景覆盖核对（少一个即报错）、链序×泳道冲突、连线端点存在性。产出自包含 HTML，可直接发人。
